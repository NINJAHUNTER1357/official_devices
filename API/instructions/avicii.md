# 🧹 Clean Flash (Required when switching ROMs)

⚠️ **This will erase all your data. Backup everything before proceeding.**

### Steps

**1.** Boot into **PitchBlack Recovery**

**2.** Flash the **ROM.zip**

* Internal Storage
* USB OTG
* ADB Sideload

**3.** Perform **Format Data**

* Type `yes` to confirm

**4.** Reboot to **System**

⏳ First boot may take **5–10 minutes**.

---

# 🔄 Dirty Flash (Updating the same ROM)

> Only recommended when updating from a previous build of the **same ROM**.

### Steps

**1.** Reboot into **Recovery**

**2.** Flash the **ROM.zip**

* Internal Storage
* USB OTG
* ADB Sideload

**3.** Reboot to **System**

✅ Your apps and data will remain intact.

---

# 🚀 OTA Update

### Steps

**1.** Open **Updater**

**2.** Install the update

* Via OTA push notification
* Or import the package using **Local Update**

**3.** Reboot after installation

---

## ⚠️ Important Notes

* ❌ Do **NOT** restore system apps using Titanium Backup or similar tools.
* 🔋 Ensure at least **50% battery** before flashing.
* 💾 Always keep a backup of important data.
* 🛑 If you encounter issues after a dirty flash, perform a clean flash.
